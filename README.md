# GreenThumb

Mobile-first PWA shell for GreenThumb.

## Build 1 goals
- Reliable app shell with no external runtime dependencies
- Exact approved GreenThumb logo asset
- Botanical field-journal visual system
- Home, Identify, My Garden, Discover, and Settings flows
- Camera/photo upload inputs
- Local-only profile persistence
- Installable/offline-capable PWA shell

## Local testing
Run any static server in this directory, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
